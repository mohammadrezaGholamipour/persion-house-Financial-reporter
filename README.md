# سیستم مغایرت‌گیری ماژول و سامانه مودیان (نسخه ۵)

## اجرا
```
py -m pip install -r requirements.txt
py main.py
```
بدون آرگومان، منوی مدیریت فایل‌ها باز می‌شود: افزودن فایل (مسیر + نوع ماژول/مودیان)، حذف فایل، تغییر آستانه، شروع محاسبه. از هر نوع می‌توان چند فایل داد (ادغام می‌شوند). نوع هر فایل را شما مشخص می‌کنید؛ برنامه از روی عنوان ستون‌ها هم تشخیص می‌دهد (ستون «موضوع صورتحساب» = مودیان) و اگر با انتخاب شما نخواند هشدار می‌دهد.
اجرای مستقیم: `py main.py --module=ماژول.xlsx --tax=مودیان.xlsx` یا `py main.py فایل۱ فایل۲` (نوع از روی ستون‌ها). حین اجرا نوار پیشرفت، درصد و زمان باقی‌مانده و اطلاعات استخراج‌شده در ترمینال نمایش داده می‌شود. بعد از محاسبه، نتیجه در `output/report.db` (SQLite) ذخیره می‌شود و گزارش در مرورگر روی `http://127.0.0.1:8765` باز می‌شود. برای فقط ساختن دیتابیس: `--no-serve`.
فایل‌های لازم کنار هم باشند: `main.py`، `server.py`، `index.html`.

## قواعد
- کلید مقایسه: شناسه فروش اصلی. برای هر شناسه، فروش و برگشت هر دو سیستم جداگانه جمع و «فروش، برگشت و خالص» مقایسه می‌شود.
- ماژول ابطال و اصلاحی را «برگشت از فروش» ثبت می‌کند؛ نوع واقعی از روی ردیف‌های مودیان (موضوع ابطالی/اصلاحی/برگشت از فروش با همان مرجع) تعیین می‌شود.
- ابطال: فاکتور ابطال‌شده از جمع و مغایرت مبلغی کنار می‌رود؛ فقط اختلاف وضعیت ابطال گزارش می‌شود.
- اصلاحی: در مبلغ نمی‌آید و در «کنترل داده» گزارش می‌شود.
- برگشت دوره قبل (بدون فروش اصلی در فایل): در خالص لحاظ و مقایسه می‌شود.
- آستانه: ۱۰ هزار تومان (۱۰۰ هزار ریال)؛ اختلاف کمتر یا مساوی و اختلاف صفر نمایش داده نمی‌شود (قابل تغییر در صفحه یا `THRESHOLD_TOMAN`).
- ردیف‌های برگشت کاملاً یکسان در ماژول (بدون شناسه) جمع می‌شوند ولی در «کنترل داده» برای بررسی لیست می‌شوند.
- مبلغ کل = جمع ناخالص + مالیات. اگر ماژول ستون «جمع تخفیفات» غیرصفر داشته باشد، برنامه در ترمینال می‌پرسد ناخالص قبل یا بعد از تخفیف است (یا با `--discount=before` / `--discount=after`). مبالغ ریال فرض می‌شوند.

## ساختار پوشه (برای نمایش گزارش)
```
main.py  server.py  index.html  requirements.txt
css/font.css                      (تعریف فونت KalamehWeb)
assets/font/woff2|woff|eot/       (فایل‌های فونت؛ نام مثل KalamehWeb(FaNum)-Regular.woff2)
assets/vendor/echarts.min.js      (نسخه محلی چارت؛ پشتیبان CDN)
```
چارت‌ها اول از jsDelivr، بعد cdnjs و در صورت نبودن اینترنت از نسخه محلی بارگذاری می‌شوند.
